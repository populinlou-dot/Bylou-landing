# ByLou Yoga - Landing Page

## Descripción

Landing page oficial de **ByLou Yoga**. 
"Clases de yoga con base científica. Regulá tu sistema nervioso, mejorá tu atención y gestioná el estrés con neurociencia práctica."

## Tecnologías Utilizadas

Este proyecto está construido con herramientas modernas de desarrollo web:
- [Next.js](https://nextjs.org/) (React framework)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/) para estilos
- [Radix UI](https://www.radix-ui.com/) para componentes accesibles
- [Lucide React](https://lucide.dev/) para iconos

## Instalación y Uso Local

1. Clonar el repositorio:
   ```bash
   git clone <url-del-repositorio>
   cd Bylou-landing
   ```

2. Instalar dependencias usando pnpm (recomendado) o npm:
   ```bash
   pnpm install
   ```

3. Iniciar el servidor de desarrollo:
   ```bash
   pnpm run dev
   ```

4. Abrir [http://localhost:3000](http://localhost:3000) en el navegador para ver la página.
